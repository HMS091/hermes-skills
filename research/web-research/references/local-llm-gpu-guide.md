## 一、论坛核心结论

**生态 > 显存 > 算力 & 带宽** — NVIDIA >>> AMD > Apple >> Intel

### 24G 显存是分水岭
- **16G**: 玩具级，能玩但不能正经用

## 二、RTX 3090 24GB vs RX 7900 XTX 24GB 对比

| 对比项 | RTX 3090 24G | RX 7900 XTX 24G |
|--------|-------------|------------------|
| **二手价格(2026.5)** | ¥5,500-7,000 ($850-950) | ¥4,500-5,500 ($700-1,000) |

| **论坛评价** | 🏆 性价比之王 | 性价比高但需折腾 |

### 7900 XTX 已知踩坑（来自用户 stakira）

1. **驱动陷阱**：Windows 自动装驱动后，再装 AMD 官方驱动会导致显卡消失
2. **解决方法**：必须用 `AMD Cleanup Utility` 彻底清除旧驱动，再装官方驱动
3. **Windows 更新驱动性能极差**：只有 16 t/s（正确安装后 35-45 t/s）
4. **物理尺寸**：3槽厚 + 3个8pin电源口，机箱和电源要求高

### 7900 XTX 优化方案（来自用户 CHIA AN YANG）

1. **KV Cache 量化**: `-ctk q4_0 -ctv q4_0`（替代默认 q8_0），Prefill 速度 +94%~+167%
2. **关闭 Qwen3 Thinking**: `--reasoning off`，解决无限生成卡死问题
3. **启用 MTP**: `--spec-type draft-mtp --spec-draft-n-max 3`，结构化输出提速 +68~116%
4. **最终成果**: Qwen3.6-27B 达 62-80 t/s（接近 4090 水平）

### 用户画像：张鑫磊的装机理念

**硬件配置：**
- 主机：零刻 GTI15（CPU i9-285H）+ 零刻原厂显卡坞（600W，直插 PCIE）
- 内存：64GB
- 存储：6TB 固态合计
- 显卡：蓝宝石 7900 XTX 白金版 24GB（¥5,450，淘宝+88vip+交行信用卡优惠）
- 双系统：Ubuntu 26.04（ROCm）+ Windows Server 2025（Vulkan）

**装机理念总结：**

1. **迷你主机 + 外置显卡坞可行** — 小体积、不占空间，零刻方案已验证可满血跑 417W 稳定
2. **电源余量必须充足** — 显卡坞 600W > 显卡峰值 420W，3×8pin 完美均衡负载（1口~180W, 2+3口各~120W），烤机 30 分钟 70°C 无波动
3. **双系统各取所长** — Linux 跑 ROCm 大模型 + Windows 跑 Vulkan/ComfyUI，模型放共享数据盘两边挂载
4. **AMD 用户用 AMD 专用包** — 秋叶整合包（NVIDIA 为主）用不了，换"机智整合包"（AMD 专用 ComfyUI 整合包，24个预装工作流）立刻跑通
5. **先跑通再优化** — 先用现成整合包验证环境，后续再自己编译 MTP/TurboQuant 调参
6. **环境隔离** — AMD 和 NVIDIA 的 ComfyUI 环境不要混用，NVIDIA 工作流可能弄坏 AMD 环境
7. **低成本起步** — ¥5,450 拿下 7900 XTX，整体方案不超 ¥10,000

## 五、关于"机智启动器/机智整合包"

**找到答案了！** 用户说的不是"机智启动器"而是 **"机智整合包"** — 一个专门适配 AMD 显卡的 ComfyUI 整合包。

### 机智整合包（AMD ComfyUI Bundle）

| 项目 | 内容 |
|------|------|
| 定位 | 对标"秋叶整合包"的 AMD 版本 |
| 适用 | **AMD 显卡**（7900 XTX / R9700 等）在 Windows 下运行 ComfyUI |
| 内容 | 24 个预装工作流、模型、节点 |
| 声音 | GPU 满载风扇声盖过 CPU，无其他杂音 |
| 来源 | 张鑫磊实测可用，替代秋叶包（N 卡专用） |

### AMD Windows ComfyUI 方案总结

| 方案 | 说明 | 来源 |
|------|------|------|
| 机智整合包 🏆 | AMD 专用整合包，开箱即用 | 张鑫磊实测 |
| 秋叶整合包 | 主攻 NVIDIA，AMD 可能不兼容 | 论坛反馈 |
| ComfyUI 官方 AMD Portable 版 | 兼容性不如秋叶，但性能更强 | terry 推荐 |
| DirectML 方案 | 最简单，`pip install -r requirements.txt` 直接跑 | 官方方案 |
| ROCm for Windows | 性能最好但安装最复杂（需找 7.2+ 版本） | 用户 CHIA AN YANG |

### Windows ROCm 安装注意事项（张鑫磊实际踩坑）
- AMD 官网只能下载到 ROCm 7.1，新版 7.2/7.3 需自己找（Gemini 可帮忙找链接）
- `rocm-smi.exe` 在 Windows 下可能不存在，与 Linux 不同
- HIP SDK 安装可能缺少关键文件，需确认版本匹配
- Vulkan 后端比 ROCm 更容易配置跑通
