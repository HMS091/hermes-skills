# Dework Platform Research

**Researched:** June 1, 2026
**URL:** https://app.dework.xyz/

## Findings

### What Dework Is
A task management platform for DAOs (decentralized autonomous organizations). Think Trello/Asana but for Web3 communities. Organizations post bounties/tasks that contributors can claim and complete for crypto payments.

### Accessibility
- **Requires Web3 wallet** (MetaMask, WalletConnect) to sign in — no email/password option
- **No public API** for searching/claiming bounties without authentication
- The explore page shows ~650 total bounties across ~65 pages

### Automation Potential
**LOW.** The platform is designed around:
- Manual wallet connection for authentication
- Manual task claiming via UI
- No API-first architecture
- Stale bounties (most are months old)
- Web3/blockchain focused (Solidity, DeFi) — not Python/automation territory

### Verdict
**Not suitable for autonomous agent operation.** The wallet requirement, lack of API, stale bounties, and Web3-specific focus make this a poor fit. Stick with GitHub Bounties for automated earning.
