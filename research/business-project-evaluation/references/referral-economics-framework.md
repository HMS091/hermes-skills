# 推荐裂变模式经济模型评估框架 (Referral Economics)

## 适用场景

用户问"推荐X返1"、"拉人头"、"裂变模式"等商业模型是否可行——评估某个产品是否适合做推荐裂变。

## 核心公式

```
推荐裂变盈利条件：

每推荐收益 = N × 客单价 × 毛利率
N = 用户需完成的推荐人数
每单成本 = 客单价 × (1 - 毛利率)
送1份的总成本 = 每单成本 + 履约物流成本(实物)
```

### 盈利临界点

| 毛利率 | 推荐3返1每3单总毛利 | 送1份成本 | 净赚 |
|--------|-------------------|----------|------|
| 95% | 3 × ¥10 × 95% = ¥28.5 | ¥0.5(数字0边际成本) | ¥28 ✅ 暴利 |
| 80% | 3 × ¥10 × 80% = ¥24 | ¥2 | ¥22 ✅ 很赚 |
| 60% | 3 × ¥10 × 60% = ¥18 | ¥4 | ¥14 ✅ 可行 |
| 40% | 3 × ¥10 × 40% = ¥12 | ¥6 | ¥6 ⚠️ 薄利 |
| 20% | 3 × ¥10 × 20% = ¥6 | ¥8 | -¥2 ❌ 亏本 |

**门槛：毛利率 ≥ 60% 才能玩推荐裂变，≥ 80% 才划算。**

## 数字产品 vs 实物产品 裂变成本对比

| 成本项 | 数字产品(模板/SaaS/课程) | 实物产品(面膜/食品) |
|--------|----------------------|-------------------|
| **赠品成本** | ¥0 (零边际成本) | ¥1-10 (产品出厂价) |
| **物流成本** | ¥0 (无需配送) | ¥3-8/单 (快递+包装) |
| **退货损耗** | 0% | 5-15% (拆封不可二次销售) |
| **合规成本** | 0 | ¥500-2000/单品备案 |
| **库存压力** | 0 | 需压货 |
| **送1份真实成本** | **≈¥0** | **¥4-18/份** |

**结论：数字产品天然适合推荐裂变（送1份成本=0），实物产品需要高加价率支撑。**

## 实物产品「推荐3返1」完整成本模型

### 以面膜为例

```
假设中端面膜零售¥29/片，出厂¥3/片

推荐3返1方案（买4片，推荐3人各买4片）：

客户A买4片：
  收入：4 × ¥29 = ¥116
  成本：4片出厂¥12 + 快递¥5 + 包装¥2 = ¥19
  毛利：¥97 (83%)

推荐3人各买4片 = 12片：
  收入：12 × ¥29 = ¥348
  成本：12×¥3=¥36 + 运费3×¥5=¥15 + 包装¥6 = ¥57
  毛利：¥291 (83%)

送A免单1片：
  成本：¥3(出厂) + ¥5(快递) + ¥2(包装) = ¥10

总净利润：¥291 - ¥10 = ¥281
总体毛利率：¥281/¥464 = 60% ✅ 可行但比数字产品低
```

### 低端面膜（零售¥5/片，出厂¥1/片）— 亏本模型

```
客户A买4片：
  收入：4 × ¥5 = ¥20
  成本：4×¥1=¥4 + 快递¥4 + 包装¥1 = ¥9
  毛利：¥11 (55%)

推荐3人各买4片 = 12片：
  收入：12 × ¥5 = ¥60
  成本：12×¥1=¥12 + 运费3×¥4=¥12 + 包装¥3 = ¥27
  毛利：¥33 (55%)

送A免单1片成本：¥1+¥4+¥1 = ¥6
总净利润：¥33 - ¥6 = ¥27
总体毛利率：¥27/¥80 = 33% ❌ 太低
```

## 推荐裂变的不适合条件

以下任一成立时，推荐裂变不适合该产品：

1. **毛利率 < 60%** → 送不起
2. **物流成本 > 产品成本的30%** → 运费吃掉利润
3. **退货率 > 10%** → 裂变来的客户退货更多
4. **客单价 < ¥5** → 裂变意愿低（推荐麻烦不值得）
5. **使用频率 < 月1次** → 用户忘记推荐，裂变链断裂
6. **无法追踪推荐**（线下现金交易）→ 没有数据支撑

## 最佳裂变方案设计

| 方案类型 | 适合产品 | 用户动机 | 成本 |
|---------|---------|---------|------|
| **推荐3返1** | 高毛利消耗品/数字内容 | 实惠，推荐=省钱 | 送1份成本 |
| **返现 ¥X** | 中单价实物 | 直接利益 | ¥X现金 |
| **双方得券** | 订阅服务 | 对自己和朋友都有利 | 折扣成本 |
| **积分/等级制** | 高频平台 | 长期粘性 | 积分成本 |
| **内容解锁** | 课程/资料 | 利他+成就感 | 0成本 |
